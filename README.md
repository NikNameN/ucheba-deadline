# Учёба — дедлайны

Общий список заданий и дедлайнов. Данные в **GitHub Issues**, правка с телефона через приложение GitHub.

Сайт после включения Pages:
https://niknamen.github.io/ucheba-deadline/

## С телефона

1. Приложение GitHub.
2. Репозиторий NikNameN/ucheba-deadline.
3. Issues → New issue → шаблон «Задание».
4. Закрыть issue = сделано.

Друзьям: Settings → Collaborators → Write.

## Pages

Settings → Pages → Branch `master` / root → Save.
